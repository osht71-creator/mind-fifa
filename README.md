بطولة فيفا — مايند
==================

1) الشعار: حط شعار مايند باسم  logo.png  جنب index.html  (يظهر تلقائيًا أعلى المنتصف).

2) Firebase (عشان الطلاب يسجلوا من جوالاتهم وتظهر أسماؤهم على الشاشة):
   - افتح console.firebase.google.com ← مشروعك (أو مشروع جديد)
   - Build ← Firestore Database ← Create database
   - تبويب Rules: الصق محتوى ملف firestore.rules ثم Publish
   - Project settings ← Your apps ← Web (</>) ← انسخ firebaseConfig
   - افتح index.html والصق القيم داخل  firebase: { ... }  في أعلى الملف
   - غيّر adminPin (رمز الإدارة) من 2026 لرقم تختاره

3) الرفع: اسحب المجلد كامل على app.netlify.com/drop  (أو Cloudflare Pages)

4) الروابط:
   - رابط الطلاب للتسجيل:     https://موقعك/
   - شاشة التلفزيون:           https://موقعك/#screen
     (فيها QR كود يوجّه الطلاب لرابط التسجيل)

5) يوم البطولة على الشاشة:
   - اضغط زر الترس أسفل اليسار ← اكتب الرمز ← تظهر أزرار الإدارة
   - «إجراء القرعة» يقفل التسجيل ويوزّع الفرق عشوائيًا
   - اضغط على الفريق الفائز في كل مباراة ← يتأهل والخاسر يُشطب
   - إذا اكتمل الدور ينشأ الدور التالي تلقائيًا، وبعد النهائي تظهر شاشة البطل
   - «تراجع» يلغي آخر ضغطة، «إعادة فتح التسجيل» يلغي القرعة، «مسح كل الفرق» لبطولة جديدة

ملاحظة: بدون إعدادات Firebase تشتغل الصفحة بوضع التجربة (على نفس الجهاز فقط) —
تقدر تفتح تبويبين: واحد للتسجيل وواحد #screen وتجرب.
